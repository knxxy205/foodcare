# Use Cases

## Donatur

- Register account.
- Login and logout.
- View programs and program details.
- Donate through payment simulation.
- View profile and donation history.

## Admin

- Manage programs, donations, purchases, inventory, relawan, beneficiaries, and distributions.
- Run FEFO and warehouse simulation workflows.
- Generate nearest-distance-first route recommendations.
- View dashboard widgets and reports.

## Relawan

- Access Filament.
- Manage assigned sorting and packaging work.
- Update assigned distribution tasks.
- Upload distribution proof.
